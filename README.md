TASK 1: #Sales & Revenue Analysis Dashboard – Power BI

* Developed an interactive **Power BI dashboard** to analyze sales, revenue, profit, orders, products, regions, and customer segments.
* Created **KPI cards, monthly sales trends, category analysis, regional analysis, and Top 10 product visualizations**.
* Added interactive **slicers for Region, Category, Segment, and Order Date** for dynamic analysis.
* Identified key business insights such as **top-selling categories, highest-performing regions, customer segments, and products**.

TASK 2: #Customer Segmentation Project

- Performed customer data analysis using Python, Pandas, Matplotlib, and Seaborn.
- Analyzed customer demographics, annual income, and spending behavior using EDA.
- Applied K-Means Clustering and the Elbow Method to divide customers into 5 segments.
- Visualized customer segments and identified high-value, regular, and low-spending customer groups.
- Generated business insights that can help with targeted marketing, personalized offers, and customer engagement.


TASK 3: #Predictive Analytics Using Historical Data

* Analyzed historical sales data to identify **sales trends and patterns** using Python, Pandas, and Matplotlib.
* Cleaned and preprocessed the dataset, including **date conversion and monthly sales aggregation**.
* Built a **Linear Regression model** to predict future sales based on historical trends.
* Evaluated the model using **Mean Absolute Error (MAE) and R² Score** and visualized actual vs predicted sales.
* Generated a **6-month future sales forecast** along with category, region, and top-product sales insights.
